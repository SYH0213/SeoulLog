### 2. Step 4/5에서 Event Loop 충돌 문제

**문제:**
- 52개 파일 처리 시 Step 4 시작하자마자 `RuntimeError: Event loop is closed` 에러
- 10개 파일은 정상 작동하지만 52개는 실패

**원인:**
```
Step 1: asyncio.run() → Loop A 생성/종료 (불완전한 정리)
Step 2: asyncio.run() → Loop B 생성/종료 (불완전한 정리)
Step 4: asyncio.run() → Loop C 생성 시도 → 이전 loop 잔여 리소스 충돌 💥
```

- 각 Step마다 `asyncio.run()`을 호출하면서 새 event loop 생성
- 이전 loop의 HTTP 연결, Task들이 완전히 정리되지 않음
- 52개 파일 처리 시 누적된 리소스가 Windows 한계 초과

**수정 파일:**
1. `database/generate_ai_summaries.py` (Line 365-370)
2. `database/generate_attachment_summaries.py` (Line 372-377)

**수정 내용:**
```python
def generate_ai_summaries():
    # Windows에서 nested asyncio.run() 지원
    import sys
    if sys.platform == 'win32':
        asyncio.set_event_loop_policy(asyncio.WindowsProactorEventLoopPolicy())

    return asyncio.run(generate_ai_summaries_async())
```

**해결 방법:**
- Windows Proactor Event Loop Policy 설정
- 이전 loop 잔여물 무시하고 강제로 새 loop 생성

**한계:**
- 근본 원인 해결은 아님 (메모리 누수 여전히 존재)
- 동작은 정상이지만 리소스 정리가 불완전
- 로그에 경고 메시지 발생 가능 (무시해도 됨)

**근본 해결책 (향후 개선):**
- 전체 파이프라인을 하나의 `async def pipeline_async()`로 통합
- `asyncio.run()` 한 번만 호출
- 모든 Step이 같은 event loop 사용
- 완벽한 리소스 관리 + 더 빠른 실행 속도

### 3. `--start-from` 옵션 추가

**요구사항:**
- 특정 Step부터 파이프라인 실행 시작
- Step 1-3이 이미 완료된 경우 Step 4부터 실행하고 싶음

**수정 파일:**
- `scripts/rebuild_all_db.py` (Line 308-533)

**추가된 기능:**
```bash
# Step 4부터 시작 (Step 1-3 건너뛰기)
python scripts/rebuild_all_db.py --start-from 4

# Step 5만 실행
python scripts/rebuild_all_db.py --start-from 5

# Step 2부터 시작
python scripts/rebuild_all_db.py --start-from 2

# Step 3부터 시작
python scripts/rebuild_all_db.py --start-from 3
```

**동작 방식:**
- `--start-from N` 옵션 사용 시 Step N 이전은 모두 건너뜀
- DB 초기화 안 함 (기존 데이터 유지)
- 비용 추적은 실행된 Step만 계산
- 로그에 "건너뛰기" 메시지 표시

**구현 내용:**
```python
# 옵션 파싱
parser.add_argument("--start-from", type=int, metavar="STEP",
                    choices=[2, 3, 4, 5],
                    help="특정 Step부터 시작")

# 각 Step에 조건 추가
if not args.start_from or args.start_from <= 4:
    # Step 4 실행
else:
    # Step 4 건너뛰기
```
